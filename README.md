
# ❤️ Heart Disease AI Prediction System

A machine learning based web application for heart disease risk prediction.

## Machine Learning Model

The final selected model is:

**Random Forest**

Model Accuracy:

**80.50%**

## Features

The application uses the following patient information:

- General Health
- Exercise
- Depression
- Diabetes
- Sex
- Age Category
- Weight
- BMI
- Smoking History
- Alcohol Consumption

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Random Forest

## Application Workflow

User Input
↓
Data Preprocessing
↓
Feature Transformation
↓
Random Forest Model
↓
Risk Probability
↓
Risk Classification

## Disclaimer

This application is developed for research and educational purposes only.

The prediction generated by this application is not a medical diagnosis and should not replace professional medical advice.
